# InterviewAI

Production-ready AI Interview Platform using microservices architecture.

## Architecture
- Microservices with Docker
- Provider abstraction for AI/Voice
- Stage-based development

## Getting Started
\`\`\`bash
pnpm install
pnpm dev
\`\`\`

## Services
- api-gateway
- auth-service  
- interview-service
- ai-service
- voice-service
- code-service
- notification-service
